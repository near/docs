Now we've updated the contract to include an NFT as a reward and changed the contract such that it accepts bids in fungible tokens, we need to update the frontend accordingly.

From the repository root, navigate to `frontends/03-frontend`. Use Node.js 22.12 or newer, copy `.env.example` to `.env.local`, and set `NEXT_PUBLIC_AUCTION_CONTRACT` to your initialized FT/NFT auction. Set `NEXT_PUBLIC_NETWORK_ID` to the correct network and optionally override `NEXT_PUBLIC_RPC_URL`.

```bash
cp .env.example .env.local
npm ci
npm run dev
```

Before bidding, transfer the NFT to the auction account and register the auction, bidders, and auctioneer on the FT contract, as covered in the [previous section](/web3-apps/tutorials/mastering-near/3.2-ft#registering-users-in-the-ft-contract).

## Displaying the NFT

We want to show what NFT is being auctioned. To do this we will call `nft_token` on the NFT contract to get the NFT metadata. To call this method we need to specify the NFT `contractId` and the `token_id`, which can be found in the auction information. `nft_token` also returns the owner of the NFT, so we'll check this against the contract account to verify that the auction is valid.

Both helpers use integer arithmetic and return strings so token amounts retain their full precision. The number of decimals comes from `ft_metadata`; for DAI it is 18.

## Bidding with FTs

Instead of calling the function `bid` on the contract we now call the `ft_transfer_call` function on the FT contract. This function transfers the FTs to the auction contract and calls the `ft_on_transfer` on the auction contract. We attach exactly 1 yoctoNEAR and 300 Tgas to the call.

The result of `ft_transfer_call` reports how many tokens were used. If it returns zero, the frontend displays an error explaining that the bid was rejected and the tokens refunded. After a successful bid or claim, the page reloads to show the updated state.

{/* github-code

```javascript title="index.js" lines
const bid = async (amount) => {
  const real_amount = parseUnits(amount, ftDecimals)
  let response = await wallet.callMethod({
    contractId: auctionInfo.ft_contract,
    method: "ft_transfer_call",
    deposit: '1',
    args: { "receiver_id": AUCTION_CONTRACT, "amount": String(real_amount), "msg": "" },
    gas:"300000000000000"
  })
  if (BigInt(response ?? '0') === 0n) {
    throw new Error('The auction rejected this bid and refunded the tokens');
  }
  window.location.reload();
  return response
}
```
