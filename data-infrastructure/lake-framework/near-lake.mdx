NEAR Lake was an AWS S3-based service for indexing NEAR blockchain data. It stopped indexing new blocks on **March 24, 2026** and is no longer maintained.

Choose a replacement based on what your application needs:

- **[Neardata](https://docs.fastnear.com/neardata)** for ingesting blocks into your own application or indexer.
- **[Data APIs](/data-infrastructure/data-api)** for querying indexed accounts, transactions, assets, and events.
- **[Nearcore indexer](/data-infrastructure/near-indexer)** for processing blocks from a node you operate.

Migrating a Lake consumer to Neardata requires changing how it fetches data. Neardata serves a block and its shards together in a single JSON response, while Lake stored separate block and shard files in S3. See [FASTNEAR's API documentation](https://github.com/fastnear/neardata-server#api) for the response format.
