## Smart Contracts

Smart contracts are programs that live on the blockchain: they store data, hold tokens, and execute code when users call their functions. In NEAR, contracts are written in Rust.

<Card title="Smart Contract Quickstart" icon="rocket" href="/smart-contracts/quickstart" cta="Start here" arrow horizontal>
  Create, test and deploy an auction contract.
</Card>

#### Tools you will use

<CardGroup cols={2}>
  <Card title="near-sdk-rs" icon="book-open" href="/tools/sdk">
    The official SDK to write contracts in Rust.
  </Card>
  <Card title="NEAR Sandbox" icon="test-tube" href="/smart-contracts/testing/integration-test">
    Tests your contract locally, no account needed.
  </Card>
  <Card title="NEAR CLI" icon="terminal" href="/tools/cli">
    Creates accounts, deploys contracts, and calls their functions from the terminal.
  </Card>
  <Card title="cargo-near" icon="package" href="https://github.com/near/cargo-near">
    Creates, builds and deploys contracts.
  </Card>
</CardGroup>

## Multichain Apps

NEAR accounts and contracts can sign transactions for other chains, such as Bitcoin, Ethereum and Solana, and users can swap assets across chains by simply expressing the outcome they want.

<CardGroup cols={2}>
  <Card title="Chain Signatures" icon="key" href="/chain-abstraction/chain-signatures/implementation" cta="Start here" arrow>
    Sign transactions for other chains from a NEAR account or contract.
  </Card>
  <Card title="NEAR Intents" icon="repeat" href="/chain-abstraction/intents/overview" cta="Start here" arrow>
    Let users swap assets across chains, with solvers competing to fill their request.
  </Card>
</CardGroup>

#### Tools you will use

<CardGroup cols={3}>
  <Card title="chainsig.js" icon="code" href="/chain-abstraction/chain-signatures/implementation">
    Builds and signs transactions for other chains from TypeScript.
  </Card>
  <Card title="omni-transaction-rs" icon="code" href="https://github.com/near/omni-transaction-rs">
    Builds transactions for other chains from Rust, including from within a contract.
  </Card>
  <Card title="1Click SDKs" icon="shuffle">
    Request cross-chain swaps through NEAR Intents, from [TypeScript](https://github.com/defuse-protocol/one-click-sdk-typescript), [Rust](https://github.com/defuse-protocol/one-click-sdk-rs) or [Go](https://github.com/defuse-protocol/one-click-sdk-go).
  </Card>
  <Card title="intents-sdk" icon="package" href="https://github.com/defuse-protocol/sdk-monorepo/tree/main/packages/intents-sdk">
    SDK to build intents-based applications.
  </Card>
  <Card title="NEAR Intents Docs" icon="book-open" href="https://docs.near-intents.org/near-intents">
    The complete documentation of NEAR Intents.
  </Card>
  <Card title="NEAR Intents Explorer" icon="search" href="https://explorer.near-intents.org/">
    Explore the transactions made through NEAR Intents.
  </Card>
</CardGroup>
